#  Coffee House — Gamified Coffee Ordering Experience

A creative, portfolio-focused web project where ordering coffee feels like playing a mini-game — not just filling out a form. Built from scratch using HTML, CSS, and JavaScript, with a focus on interactive UX, smooth animations, and clean state management.

##  Concept

Instead of a traditional "add to cart" flow, this project reimagines coffee ordering as an immersive experience:
- A cinematic drone-zoom landing page welcomes users into a virtual coffee shop
- Users can either jump straight into ordering ("Urgent Order") or explore the shop first ("Enter Shop")
- Inside the shop, a smooth drone-to-first-person transition sets the scene
- A dedicated "Coffee Builder" lets customers fully customize their coffee — type, milk, sugar — with live price updates

##  Features

- **Live price calculation** as options are selected, before adding to order
- **Dynamic order management** — add, view, and remove items with a single click
- **Empty state handling** for a polished, no-dead-ends UX
- **Sparkle micro-interaction** on order confirmation (used sparingly, only on key actions, to avoid visual noise)
- **Smooth page transitions** between Landing → Shop Interior → Coffee Builder
- **Fully responsive design** across mobile and desktop
- **Custom dark, warm aesthetic** consistent across all pages

##  Tech Stack

- HTML5
- CSS3 (custom animations, Flexbox, media queries)
- Vanilla JavaScript (no frameworks — state management, DOM manipulation, and event handling built from scratch)
- [RemixIcon](https://remixicon.com/) for iconography

##  Pages

| Page | Description |
|---|---|
| Landing Page | Drone-zoom intro with "Enter Shop" and "Urgent Order" options |
| Shop Interior | Drone-to-POV transition, leads to Coffee Builder |
| Coffee Builder | Full ordering system with live pricing and order management |

##  How to Run

1. Clone this repository
```bash
   git clone https://github.com/fizasandhu6-ctrl/coffee-house.git
```
2. Open `index.html` in your browser — no build tools or dependencies required
